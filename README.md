# 🧪 Practice Task: Data Cleaning and Visualization with Pandas

This is a beginner-friendly data science project to practice working with pandas, data cleaning, and data visualization using matplotlib. The task involves loading a dataset of article information, removing null values, and visualizing the article categories using a bar chart.

## 📁 Dataset

A small sample dataset named `articles.csv` containing article information with the following columns:
- `id`: Unique article ID
- `title`: Article title
- `category`: Category of the article (e.g., Programming, Lifestyle, Technology)

## ✅ Objectives

- Load data using **pandas**
- Clean data by removing **null values**
- Visualize **article categories** using **matplotlib**

## 📊 Output

The final output is a **bar graph** showing the number of articles in each category, helping understand category distribution.

## 🧰 Tools Used

- Python 🐍
- Pandas
- Matplotlib
- Jupyter Notebook

## 📎 How to Run

1. Clone or download the repository
2. Open the `.ipynb` file in Jupyter Notebook
3. Run all cells to see the output
